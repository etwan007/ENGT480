# Setup Project

This project use `uv` as python package manager. Use `git` for version manage.

## Setup Environment

Setup `git`

```bash
sudo apt install git
```

Setup `uv`

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Clone Project

```bash
cd ~/
git clone https://github.com/etwan007/ENGT480.git
```
