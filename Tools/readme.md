# Tool

## MCU Firmware Build

### Setup

Setup env

```bash
./Tools/mcu-build/setup-pio.sh
```

### Build ESP TX (Legacy) Firmware

Build ESP TX (legacy) Firmware

```bash
./Tools/mcu-build/build-tx-legacy.sh
```

## MCU Firmware Flash

```bash
./Tools/mcu-flash/flash-tx.sh sensor_1
```

Flash Sensor 2

```bash
./Tools/mcu-flash/flash-tx.sh sensor_1
```
